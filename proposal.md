# Project Proposal: Find Gamers

### Team: 
Norah Anderson, Rashi Roselin, Jennifer Yuan, Ryan Ginn

## Project Overview

Find Gamers is a web application designed to help gamers find other players to play their favorite games with. Users will be able to create personalized gaming profiles, list the games they play, provide information such as their rank and preferred role, and indicate when they are looking for teammates.
The application will include an Explore page where users can search and filter for potential teammates based on criteria such as game, region, rank, platform, role, and whether they are currently looking for teammates. Users will also be able to view other gamers' profiles and connect with people who share similar gaming interests.
The goal of the project is to create a simple, user-friendly platform that makes it easier for gamers to find compatible teammates without relying on existing social media or gaming communities.

## Technologies

The application will be built using the following technologies:

- Frontend: HTML, CSS, JavaScript, (Possibly React.js)
- Backend: Node.js with Express.js
- Database: MongoDB

## Main Feautures

### User Authentication

Users will be required to create an account and log in before using the application's main features.

Users will be able to:
- Create an account
- Log in
- Log out
- Securely store their password
- Edit their profile


### User Profiles

Each user will have an editable profile containing information such as:

- Username
- Profile picture
- Bio
- Region
- Gaming Platform
- Games they play

#### My Games

The user profile will contain a My Games section in which they can:

- Add games they play
- Set their rank
- Set their preferred role
- Toggle whether they are currently looking for teammates
- Set their playstyle (competitive, chill, etc.)

### Explore Gamers Page

The Explore page will allow users to browse other gamers.
Users will be able to:
- Search by username or game
- Filter by game
- Filter by region
- Filter by rank
- Filter by platform
- Filter by preferred role
- Filter for users who are looking for teammates

Each search result will display basic information about the gamer and provide an option to view their full profile.


### Friend Requests

Users will be able to send connection requests to other gamers.

Recipients will be able to:
- Accept a request
- Decline a request
- View pending requests
Users will also be able to view their connections.
Accepted friend requests display their gamertag (possibly messaging system if we have time).
